## 共享兼容模型

现有 `DEEPSEEK_API_KEY` 仍在后端使用。自定义服务商通过后端私密环境的 `AI_PROVIDER_PROFILES` 配置，默认 `[]`；API 与 Worker 必须采用相同配置。浏览器只接收服务商编号、名称、原始模型 ID、能力和是否可用，不接收地址或凭据。修改后要重启实际使用该配置的进程，排队期间配置变化的请求会被拒绝，需重新确认。

以下 JSON 仅说明结构。示例域名无实际服务，`api_key` 为空时不可调用；真实配置不得提交到 Git、复制进网页或日志。不要直接用示例覆盖现有服务配置。

```json
[
  {
    "id": "custom",
    "name": "兼容模型服务",
    "base_url": "https://models.example.invalid/v1",
    "api_key": "",
    "enabled": true,
    "models": [
      {
        "id": "provider-original-model-id",
        "name": "文字与工具模型",
        "text": true,
        "vision": false,
        "tools": true,
        "streaming": true
      }
    ]
  }
]
```

`base_url` 不含结尾 `/`，后端追加 `/chat/completions`；必须是受控公网 HTTPS 地址，不接受内网、异常端口、代理或重定向。能力字段须与服务实际支持一致。不同服务商可有相同模型 ID，选择由服务商编号和原始模型 ID 共同确定；不静默替换成其他模型。管理员在共享模型设置中对各服务商分别测试模型列表；这不是生成回答的端到端验收。

聊天、卡片、测验、判题、OCR 和视觉选材沿用各自入口与权限。语义索引仍使用原百炼配置及维度，不因新增聊天服务商改变嵌入协议。

工具默认关闭。显式选择本人笔记范围或学习汇总日期、查看预览并确认后才提交。工具只允许授权范围内检索、读取及统计；最多三次模型请求、六次工具调用。历史保留来源与调用状态。超时等未知结果不会自动再次付费；相同参数人工重试沿用原请求编号。更改问题或范围需重新确认。

网络总预算覆盖连接、TLS、响应头、正文与写入，不以分段持续收到字节无限延长。当前实现对 `httpx==0.28.1` 与 `httpcore==1.0.9` 的受控连接桥接做精确版本和结构校验；不兼容时拒绝连接。升级依赖前须重新验证真实本地 TLS 慢响应、阻塞写入、关闭与权限最后检查，不能删除校验后继续发布。

## 本机离线资料

首次在线时，在离线资料入口设置独立本机口令，选择缓存本人全部或部分笔记。等待组织、正文、页面及原图/PDF/阅读图下载完整，检查字节数与缺失提示后再断网。应用壳安装与私人资料缓存是两件独立操作；只安装应用不会自动下载私人资料。

离线口令解锁本机密文，不创建服务器登录。忘记口令不能找回资料；设备资料也不能替代账号导出或整站备份。浏览器清理、容量不足或驱逐可能丢失未同步内容。重新联网后先以同一账号认证，再手动同步；编辑投影与队列同事务保存，刷新不会更换已发送的操作编号。

非重叠字段可合并，同字段或页面冲突会保留本机草稿与服务器状态，需要明确选择。服务器已删除组织时，可接受删除或以新编号保存副本；不会不断向原编号重试。账号包恢复后的旧队列不能直接重放，需保留本机内容并人工核对。退出前会提示未同步资料的丢失风险，取消退出可继续同步；确认退出清理本人设备资料，失败时会明确提示并提供重试。

## 首页、推荐与学习分析

首页偏好可调整五个卡片的排序、显示及新登录默认入口，并恢复默认；全部隐藏仍可进入功能中心。同一认证会话刷新不能再次强制套用新登录默认入口。保存遇到版本冲突时保留本机输入，需明确加载服务器版本后处理。

推荐默认不使用私人学习信号。主动开启偏好或学习信号后，在当前可见社区帖子中排序并逐条解释理由，可关闭或切回最新。删除、撤回或下架内容不会因旧推荐游标重新获得访问权。阅读和活动指标是可复算事实，不等于掌握程度。

AI 学习分析默认关闭。开启后，先选择日期、时区与模型并预览确切数字汇总，再勾选确认提交。只发送批准的冻结汇总，后续普通学习活动不偷偷替换输入；关闭、退出、取消或输入变化仍阻止发送。结果区分事实、推断与样本不足。未知提交先保留原编号，刷新不会自动重发；手动重试同一待定请求也沿用原预览和编号。

账号 ZIP v5 包含首页偏好、学习分析、工具历史及保留身份的已移除页面。设备推送凭据、离线口令/密钥/队列、认证会话和临时分析预览不进入账号包；恢复不会开启 AI 分析或重发未完成付费任务。恢复指令与完整格式见 [完整导出格式](完整导出格式.md) 和 [账号归档恢复演练](账号归档恢复演练.md)。

## 安装与推送

HTTPS 或受支持的本机开发环境中，使用应用提供的安装入口；浏览器未提供安装事件时按实际平台提示操作。更新提示出现后先保存或同步未完成内容，再主动更新。私人 API 响应不会被通用 Service Worker 缓存。

推送默认关闭，后端需配置匹配的 VAPID 公私钥和 subject；私钥仅服务端保存。用户主动点击授权、注册当前设备，再发送测试提醒。拒绝权限、不支持或服务未配置时仍可查看站内通知。锁屏只显示通用提示，点击后重新核验认证。推送尽力送达，站内持久记录才是最终事实；退出、会话失效和取消订阅会阻止新投递。

模拟手机尺寸、浏览器安装条件检查、合成模型或推送替身不能证明实际手机安装或外部送达。当前验收缺口始终以开发计划和证据记录为准。
