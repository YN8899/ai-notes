## 固定边界

私人笔记、AI、学习数据仍按所有者检查；好友授权只打开专用只读入口。管理员不获得私人内容读取通行证。社区当前仅对已登录 active 成员开放，公开内容是独立副本。

社区推荐按冻结的内容完整度分数（独立图片、正文长度）及发布时间排序，逐帖说明依据；真实点赞/评论单独展示。采用冻结分数避免互动变化引起翻页重复和漏项。

账号 ZIP v4 使用 34 类集合。社交与社区记录及附件恢复为本人可读的独立历史，外部成员显示身份脱敏，不重建外部账号、好友、授权、公开发布或发送任务；v1–v3仍兼容。整站恢复完整保留真实关系和内容，但撤销旧会话/实时票据并终止未完成任务。

当前 M2 公网基线以本地 `.local/ops/` 最新记录为准；不能用本计划或 M3 本地代码代替公网发布证据。M1 已登记延期的事项不因本轮开发改成验收通过。
