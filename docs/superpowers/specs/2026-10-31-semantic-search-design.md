# T18：百炼文本向量与可选语义搜索

用户已选择“自建检索与向量库，调用阿里云百炼 embedding”，并明确继续开发。沿用 T17 权限和来源定位规则。本轮本地实现，不发布公网、不配置真实密钥、不进行真实模型调用；旧 M1 费用授权不用于本轮。

## 范围与操作

关键词为默认模式；语义搜索为用户显式提交的独立模式，不在键入、刷新、轮询、打开页面时调用模型。设置页展示脱敏配置、索引历史与状态。建索引先预览要发送的文本块数量，再确认发送；每次搜索说明查询文本也会发送百炼。只发送文本，不发送图片或 PDF 原件。未配置、索引未就绪、调用失败时保留关键词入口。

首版使用北京业务空间 HTTPS 固定域名、text-embedding-v4，默认1024维，可配置官方支持维度。密钥仅由后端环境配置，无前端密钥输入。httpx 单次请求，无自动重试、重定向或系统代理；严格校验响应数量、索引、维度、有限非零数值及大小，错误不泄漏密钥/资料。每批最多10条，每块800码点/40重叠，最多500块；超限明确拒绝，不静默截断。

## 数据与版本

增加 semantic_indexes、semantic_chunks、semantic_queries 三张表（必要的调用收据可放独立表）。索引记录完整 provider/workspace/model/dimensions/chunker 版本、请求标识、清单摘要、Job 与用量；块记录来源身份、版本/内容摘要、码点区间、文本和 pgvector 向量。查询持久化请求标识、配置/索引身份、状态与用量，不因浏览器重试重复收费。

同账号同时最多一个构建；付费构建 Job max_attempts=1，禁止通用管理员重试接口重放。每次发送前持久化调用已开始状态，租约过期/中断/未知结果视为失败，需人工发起新请求，不自动续跑。已知用量保留。重建不修改旧活动索引；完成后用户显式激活。按用户行锁串行激活，任意时刻最多一个活动版本，旧版保留可切回。模型/维度更改必须建立新版本，查询始终使用活动版本配置，不混用新默认值。

来源包括独立标题、标签、正文，以及 T17 最新有效 OCR 文本（纠错优先，空纠错覆盖原文）。所有来源限定当前账号、有效笔记/图片/PDF/识别结果。构建预览摘要在确认时重验。执行前重验来源和配置，提交前再重验租约；变化的来源不成为成功结果。检索先去除删除/变化/越权来源，再在同一索引版本内用 pgvector 精确余弦距离排序，最多20项；首版有500块上限，暂不引入近似索引。打开结果重新验证来源摘要与区间，展示只读原文/原图，过期结果要求重建或重新搜索。

## 迁移与运维

固定 PostgreSQL16.8-alpine + pgvector0.8.7 自建镜像，不改数据库主版本/存储路径；默认关闭配置仍可运行关键词。增量 migration 安装 vector 并增加表；降级删除新表但保留扩展（避免破坏其他使用者）。同步本地/测试镜像、CI 与 ACR 发布流程和缓存，保留同提交 CI 复用及安全校验。

整站备份新增精确 schema profile，保留旧27/28表兼容；恢复不重放付费任务，未结束构建/查询转终态，完整向量版本可恢复。账号 ZIP 继续 v2，向量和查询属于可重建缓存不纳入账号导出，原笔记/OCR 保持完整；文档明确恢复后重新建索引。
