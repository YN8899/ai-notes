## 真实 HTTP + PostgreSQL 整条闭环

`test_m2_workflow.py` 通过真实FastAPI HTTP接口、真实图片处理Worker、本地文件和PostgreSQL依次执行：

1. 登录合成账号，通过授权上传/PUT/complete提交真实PNG并生成阅读图。
2. 明确一次OCR，保留原文，人工纠错；关键词命中纠错并重新核验原页身份。
3. 同图预览/生成卡片草稿，确认后建立独立计划，原笔记计划不变。
4. 同图生成判断+简答草稿，确认后冻结试卷、逐题保存、交卷needs_review、人工复核为2/3。
5. 卡片切换FSRS并提交四档评价；临时练习不改计划，源笔记仍不变。
6. 保存时区/每日时刻，Worker持久账本当天只生成一次，outbox产生可跳转复习中心的通知。
7. 重复提交同event_id只记一次；统计20秒、4正式复习、1练习、正确分值与日历原始事实，阅读覆盖1/1。
8. 通过实际完整导出接口下载ZIP并用标准库校验器验证卡片/作答/事件集合。

只有OCR、卡片生成、测验生成这3次HTTP模型返回由MockTransport提供，没有真实模型网络调用。浏览器完整真实App交互另见[M2跨模块浏览器验收](2026-11-01-m2-workflow-browser.md)，不要把两种替身边界混称为真实云端或真手机。
