## 审查后的修复

- 账号身份缓存：模型调用期间禁用账号时，原 `SELECT FOR UPDATE` 不会刷新现有 SQLAlchemy 身份对象。独立内存 ORM 复现后，锁定读取加入 `populate_existing=True`；新增查询/构建期间停用测试，查询失败、结果为空、已知用量仍保留。
- 租约与锁顺序：先锁 Job 再等待 User，可能在等待后租约已过期，且心跳被 Job 锁阻挡。改为 User → Job，来源校验后再检查租约。两项真实 PostgreSQL 租约回归修复前失败（仍发起模拟 POST），修复后通过（零 POST、原活动版本保留）。专项扩展为38项通过。后端质量复审通过。
- 旧28表 CLI：内部配置档支持 OCR 版本，但参数 choices 遗漏。改为从全部冻结版本展开，实际解析器5例通过，覆盖 head/22/27/28/32表。
- 不确定 HTTP 响应：已接收/计费后仍可能返回5xx。前端保留5xx/408及网络错误的原 payload/UUID，禁止自动新建请求，提供同编号显式核对/重发。补充纯函数与实际界面500后核对验证。
