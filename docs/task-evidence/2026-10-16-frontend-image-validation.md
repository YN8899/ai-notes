整理日期：2026-10-16（Asia/Shanghai）。代码基线：`1948ce2393ac47b9f6cfa278befcd8e25ec22ed5`。

## 修改范围

- 用户名输入框中的连字符改为显式转义，兼容浏览器 HTML `pattern` 的 Unicode Sets 规则。允许的字符仍为英文字母、数字、下划线和连字符；前后端长度限制、服务端校验与账户权限未改变。
- 添加与现有书本标识一致的 `frontend/public/favicon.svg`，在入口 HTML 声明 SVG 网站图标，避免浏览器自动请求缺失的默认图标。
- 未修改 API、数据库迁移、依赖、存储实现、云端配置或部署方式。

## 2026-10-15 浏览器实际验收

环境为本机 Vite、FastAPI、独立 Worker 与 PostgreSQL 开发库，`STORAGE_BACKEND=local`。仅使用新建的合成测试笔记及两张 1200×1600 的 PNG/JPEG 测试图，不访问真实 OSS 或模型服务。

会话未提供 Browser 插件，使用已有 Playwright 和本机 Edge 155.0.4283.45；桌面视口为 1440×1100，手机尺寸视口为 390×844。

| 场景 | 实际结果 |
|---|---|
| 登录与注册页用户名校验 | 字母、数字、下划线、连字符可用；感叹号、空格及中文触发 patternMismatch；没有原来的正则编译错误 |
| 网站图标 | HTML 声明 `/favicon.svg`；请求返回 200、类型为 image/svg+xml；构建输出包含相同图标内容 |
| 图片选择与预览 | PNG、JPEG 均可预览；上传前可调整顺序 |
| 上传与后台处理 | 两张图片均上传完成，Worker 处理后状态为 ready |
| 私有图片显示 | 两张缩略图及当前阅读图实际解码成功，来源均为同源 `/api/v1/files/`；未在记录中保存短期凭证 URL |
| 图片阅读器 | 放大至 125%、鼠标拖动及重置至 100% 均生效 |
| 页序与刷新 | 上传后的页面可调整顺序；接口结果与界面一致，完整刷新后顺序保留且图片仍可阅读 |
| 页面状态 | 标题与内容正确，无 Vite 错误遮罩；手机尺寸没有页面横向溢出 |
| 浏览器错误 | 无非预期 console error、warning 或失败响应；未登录时 `/auth/me` 的 401 属于正常流程 |

临时浏览器脚本、合成图片与桌面/手机截图保存在本机工作区外，没有提交到仓库。上述结果为当日实际执行记录，不代表真实手机或真实 OSS 验收。
