# M3 好友与社区操作指南

本说明对应 M3 本地版本。公网是否已更新，以当前发布记录为准。学习卡片、测验与复习仍见[M2学习功能操作指南](M2学习功能操作指南.md)。

## 好友、关注与资料

1. 打开侧栏“好友与分享”，在“查找成员”中按用户名查找，点击“加为好友”。
2. 对方在“收到的申请”中接受或拒绝。申请发出后不会自动成为好友。
3. “关注”是独立单向关系，用于社区的“我的关注”信息流；不授予私人笔记访问权限。
4. 在“个人设置”保存显示名称、简介、学科和详细资料。详细资料默认仅好友可见，也可设置仅自己可见；学习数据不在个人主页公开。
5. “我的好友”中可以查看资料、发起私聊或解除好友。解除后旧分享不再允许新读取；重新添加好友不会恢复旧分享授权。

## 只读分享笔记

在“好友与分享 → 笔记分享”选择自己的笔记和好友，点击“创建只读分享”。笔记和好友均支持分页选择。

接收方从“收到的分享”点击“只读阅读”，可看当前正文和图片页；页面没有修改、AI 处理、历史或导出入口。分享者在“我发出的分享”撤销。笔记进入回收站、账号停用或好友关系解除也会停止新访问。已经读到或下载到设备的内容不可能远程收回。

## 私聊与附件

从好友行点击“私聊”，或从“私聊消息”打开已有会话。消息先保存到数据库，再显示成功；失败时“重试发送”保留同一请求编号，避免重发成两条。重新连接或刷新会从数据库补拉消息。

支持 PNG/JPEG/WebP、PDF、UTF-8 TXT/Markdown；单附件最多10 MiB，每条最多5个附件。先上传再发送，未发送附件不会向对方开放。本人聊天附件总量上限512 MiB，同时待发送附件最多50个。对方和非参与者均不能通过猜测附件 ID 越权读取。

首版不提供聊天消息或附件的永久删除；消息编辑框的“移除”仅从本条待发送消息中排除附件，不物理删除服务端文件。本人未发送附件仍计入容量和数量，并保留在个人归档及整站备份中。

点击“将已显示消息标为已读”推进连续可见的位置；尚未加载的历史不会因为发送一条新消息被跳过标已读。在线不等于已读。解除好友保留双方已有会话与附件，但禁止新发送。退出当前标签页会关闭实时连接并清理页面私人内容。

## 发布独立社区副本

“学习社区 → 写帖子 / 准备笔记副本”可写原创，或展开“从自己的笔记准备副本”选择自己的笔记。填写标题、学科、帖子类型和自由标签；正文沿用富文本、公式及 Markdown 编辑器。

先“创建草稿”或“保存草稿”，再显式“发布已保存的草稿/更新”。图片会在后台复制和校验，全部完成后才公开；复制失败保持不可见，可“重试上次发布”。重试使用上次已经冻结的内容；要发布新编辑，先保存，再发起新的发布。

已发布正文与图片是独立版本。编辑草稿、修改或删除私人来源不会自动改变它。同一来源版本的后续更新使用已有社区独立文件；显式选择新的来源/版本才重新读取私人资料。PDF 尚未完整成功转换时，不能发布不完整副本。

“查看当前公开版本”可阅读、下载社区副本原件。“撤回公开内容并取消发布”停止展示和新的正文/文件读取。账号停用、管理员下架也阻断信息流、收藏、评论和附件直链。

## 浏览、互动与审核

“社区发现”支持最新发布、我的关注和规则推荐，另可按学科、帖子类型、完整标签筛选和分页。规则推荐依据页面明确显示的内容完整度与发布时间，不是 AI 掌握判断。

帖子内可以发表评论、删除自己的评论、点赞、收藏；“我的收藏”只显示当前仍可见的帖子。展开“举报此公开内容”填写原因提交。失败重试不会生成重复评论或举报。

管理员在“社区审核”中核对公开帖子，填写理由后驳回或下架举报；已下架帖子可以按 ID 和理由恢复。所有操作写入审计。作者不能通过再次发布绕过下架。

## 工作台与恢复历史

“空间概览”的综合工作台显示笔记、待复习、好友申请、全部会话未读和收到的分享，并提供笔记、AI、复习、好友、消息、社区和个人设置入口。

“我的笔记 → 完整导出”下载账号 ZIP v4，包含本人的社交与社区历史及合法可读附件。命令行恢复后的历史在“个人设置 → 恢复的社交与社区历史”阅读、筛选和下载附件。它不会自动重新成为好友、授予分享或公开帖子；对方未发送附件、对方私人笔记及其他用户学习数据不在本人的账号包中。
