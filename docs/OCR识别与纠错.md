# OCR 识别与纠错

本功能为 M2 T16 的手动单页识别闭环。只有部署了本轮代码并完成相应迁移的环境才会显示入口；本地开发完成不代表公网已经更新。

## 在哪里使用

1. 进入“我的笔记”，打开图片笔记或已经完成转换的 PDF 笔记。
2. 在图片页面列表选择要处理的一页，阅读器下方会显示“文字识别 OCR”面板。
3. 保持“整页识别”，或选择“单个矩形选区”，在图上框出要识别的位置。
4. 点击“识别本页文字”，核对文件名、来源版本和发送范围，再点击“确认发送并识别”。一次只处理当前一页/选区，不自动发送整个 PDF。
5. 在“本页识别记录”查看进度，完成后打开识别记录。

没有配置共享视觉模型时，面板会说明不可用，原图阅读和其他笔记功能仍可正常使用。打开面板、刷新和查询进度不会创建模型调用；真正确认发送会使用管理员配置的共享模型，可能产生费用。

## 如何纠错和回看原图

- “模型识别原文”保留本次模型返回的文本，不能被人工编辑覆盖。
- 在“人工纠错稿”修改错字、断行或公式，核对后可勾选“我已人工核对文字与公式”，再点“保存纠错稿”。
- “预览纠错稿中的公式”只负责显示常见 LaTeX 数学定界符，不更改原文，也不能替代人工核对。
- 点击“定位原页 / 选区”打开同一来源页面；选区识别保留矩形位置。整页识别只定位整页，不声称有逐字坐标。

纠错稿独立于原图片笔记和 AI 回答保存功能，不会覆盖原图，也不会自动生成或替换原笔记正文。当前还没有 OCR 关键词搜索入口，搜索属于后续 T17。

## 失败、冲突与来源变化

- 失败、中断、取消或输出被截断不视为识别成功，也不会自动重发收费请求。先核对运行状态，确实需要时点击“重新识别（新调用）”并再次确认。
- 重新识别创建新记录，原识别和已保存纠错稿继续保留。
- 另一个页面保存了同一纠错稿时，旧版本保存会提示冲突，当前输入保留；先刷新识别记录、核对双方修改，再明确选择按最新版本保存或使用已保存文本。
- 换图、移除来源页或将来源笔记放入回收站后，旧识别显示来源失效，不能冒充当前页内容或继续保存纠错。恢复来源是否有效由真实页面/文件身份决定。
- 调整页序或改标题不把结果错误地指向其他页；提交时页码和版本仍作为历史信息显示。
- 未保存纠错稿应先保存再切换页面、关闭标签或退出。当前面板不承诺跨关闭页面恢复未保存的纠错输入。

## 导出与恢复

新版账号 ZIP 使用 v2 格式，包含 OCR 识别原文、纠错稿、复核标记与来源关系；离线校验/恢复工具仍支持旧 v1 归档。恢复只到独立空库/空目录，不自动重放识别请求，也不调用模型。具体工具边界沿用[完整导出格式](完整导出格式.md)和[账号归档恢复演练](账号归档恢复演练.md)。

## 本轮发布前准备

本轮新增 Alembic 迁移 `7c0a9d2e4f61`，父版本 `2ef16e7ca892`；新增 `ocr_documents`，不改原笔记正文，不自动识别已有文件。

本地测试使用专用临时 `notes_test`。公网仍需独立准备并获准执行发布：核对真实恢复点，先更新与新 schema 匹配的独立监测/备份/恢复工具快照，再按现有完整 HTTPS Compose 集合迁移和更新应用。依赖离线包只包含依赖，应用镜像或依赖包不会自动替换服务器运维源码及 schema 资料。

如果应用验证失败，应按具体发布方案保留新表/数据、停止新识别并评估应用回退；不能为了回退直接降级删除 OCR 表，也不能把旧快照覆盖当前有新写入的生产库。本轮尚未执行公网迁移、部署或真实模型调用。
